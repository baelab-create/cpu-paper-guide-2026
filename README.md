# CPU 특허보고서 논문화 가이드

학생 보고서의 논문화 방향과 투고 후보를 비교하는 정적 웹페이지입니다.

**공유 링크: https://baelab-create.github.io/cpu-paper-guide-2026/**

- 9개 조·10개 보고서의 조별 원고 방향과 보완 과제
- 저널 38종의 학교 등급·비용·접수 조건 검색
- 참고논문·공식 출처, 집필 가이드와 CSV 저장

조사 기준은 2026-10-07, 공유용 정리는 2026-10-28입니다.
학생 보고서 원본·대화 기록·개인 경로·다운로드한 논문 PDF는 게시하지 않습니다.
원문은 출판사·DOI·기관 공개 링크로 연결합니다.

`index.html`은 외부 라이브러리 없이 작동합니다. GitHub Pages는 main 브랜치의 루트에서 게시합니다.
